# 📊 Sales Data Analysis Project

## 🔍 Objective
To analyze sales data and generate meaningful insights.

## 🛠 Tools Used
- Microsoft Excel

## 📊 Analysis Performed
- Sales by Region
- Monthly Profit Trends
- Top Products

## 💡 Key Insights
- North region has highest sales
- December shows maximum profit
- Some products are running in loss
